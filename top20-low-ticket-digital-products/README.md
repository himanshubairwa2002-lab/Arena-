## Regenerate / re-rank it yourself

```bash
cd top20-low-ticket-digital-products
python3 build.py          # rebuilds IDEAS_DEEP_DIVE.md, top20_scored.csv, dashboard.html
```
- `global_scores.py` — the 20 ideas + global scores + global weights
- `content_1.py`, `content_2.py` — all descriptive content (what's inside, buyers, proof, hooks, watch-outs)
- `build.py` — India scores (`INDIA_SCORES`), India weights (`I_FACTORS`), and the renderers

Change a score or a weight, re-run, and the ranking moves. That's the honest way to argue with it.

> **Caveat, deliberately repeated:** every revenue figure in this pack is a reported marketplace number or creator report, not audited data. Use them as evidence that buyers exist — never as a forecast. Each idea card includes the exact searches to run so you can check current competition the week you launch.
